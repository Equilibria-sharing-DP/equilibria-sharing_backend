# equilibria-sharing_backend

Das Ziel des Projektes ist es der Firma, zeitintensive Arbeit abzunehmen und eine Web-App zu entwickeln. Je nachdem, in welchem Land etwas gemietet wurde, bekommt der Mieter einen Link zu einer Unterseite auf der Homepage der Firma, auf der Sie ein Formular ausfüllen müssen. Die Daten sollen sicher gespeichert und gelöscht werden.  Diese Daten müssen in Italien in einem Online Portal der Polizei, bzw. in Österreich unter www.app.ibindo.at,  händisch eingetragen werden. Ebenso soll es tägliche Buchungsprotokolle geben, als auch Quartalsweise eine Statistik.
